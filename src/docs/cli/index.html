Analyzes HTML source code, extracts `i18n` elements and `<script type="application/ld+json">` data, and uses Google GenAI to synthesize a Language-First JSON translation dictionary.

Parameters

html string
Raw HTML source code string containing elements with `i18n` attributes.
languages Array.<string>
Array of target language codes (e.g., `["en", "es", "fr"]`).
options TranslateOptions
Optional configuration parameters for model and authentication.

Returns

Promise.<(LanguageFirstTranslationMap|null)> Language-First translation map, or `null` if generation fails.

Examples

  '<h1 i18n="heading">Hello</h1><input i18n="search" placeholder="Search...">',
  ["es", "fr"]
);
