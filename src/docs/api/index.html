createTenantProxy

function

Creates a Proxy firewall wrapper to automatically inject multi-tenant scope parameters (`organization_id` and `host`) into target method invocations.

Parameters

target Object
Target service instance to proxy (e.g., crud or wsManager).
orgId string
Multi-tenant organization identifier.
host string
Host domain identifier.

Returns

Proxy undefined Proxied target service with auto-injected tenant parameters, or undefined if target is falsy.

send

function

Resolves endpoint definitions, executes AST macro actions, or dispatches outgoing HTTP requests.

Parameters

data Object
Execution directive payload.
data.url string
Optional pre-formatted target HTTP endpoint URL (Direct Execution Path).
data.api string
API configuration name (e.g., 'stripe-test').
data.method string
HTTP method (e.g., 'post'). A matched endpoint configuration may override it.
data.endpoint string
Stored endpoint name (e.g., 'create-customer') or direct API path (e.g., '/v1/customers').
data.data *
Request content passed to the external API.
data.searchParams Object
Query parameters appended to the request URL.
data.headers Object
Custom HTTP header directives.
data.timeout number
Request timeout in milliseconds.
data.socket Object
WebSocket client reference for real-time response emit.
data.organization_id string
Multi-tenant organization identifier.
data.host string
Target host domain.
parentContext Object null
Outer sandbox execution context when nested.

Returns

Promise.<Object> The mutated execution envelope, with response content assigned to `data.data`.
