render

init

function

Initializes elements based on specified rendering attributes. If a specific element is provided, it initializes that element. If no element is provided, it queries and initializes all elements matching the defined selector criteria for rendering attributes. Supported rendering attributes: - render-query: [Describe what this attribute does]

Parameters

element Element Array.<Element> HTMLCollection null
Optional. A single element, an array of elements, an HTMLCollection, or null. - If an HTMLCollection or an array of elements is provided, each element in the collection/array is initialized. - If a single element is provided, only that element is initialized. - If null or omitted, the function queries and initializes all elements matching the 'elementSelector'.

render

function

Asynchronously renders content based on the provided parameters. This function handles the rendering logic for elements based on data sources, selectors, and other options.

Parameters

options Object
An object containing the parameters for rendering.
options.source Object
The data source used for rendering.
options.element Element
The DOM element where content will be rendered.
options.selector string
CSS selector to specify target elements for rendering.
options.data Object
Data to be used in rendering.
options.key string
Optional key to reference specific parts of the data.
options.index number
Optional index, typically used when rendering lists or arrays.
options.currentIndex number
The current index in a list or array rendering process.
options.update boolean
Flag to indicate if the rendering should update existing content.
options.remove boolean
Flag to indicate if the rendering should remove elements instead of updating or appending.

Returns
