observer

observer

class

A highly optimized MutationObserver wrapper that allows for targeted observation based on CSS selectors, specific attribute filters, and mutation types. It maintains internal maps for tags, IDs, classes, and attributes to minimize the performance overhead of checking mutations against selectors.

init

function

Initializes the observer with the provided configuration(s). Parses selectors and distributes configurations into the internal optimized maps.

Parameters

config object Array.<object>
The configuration object or an array of configuration objects.
config.name string
The unique name of the observer (used for un-init).
config.types string Array.<string>
The MutationObserver type(s) to observe (e.g., 'childList', 'attributes', 'addedNodes', 'removedNodes').
config.attributeFilter Array.<string>
The attributes to observe (only used for 'attributes' mutations).
config.selector string
The CSS selector to target elements.
config.callback function
The callback function to execute when mutations occur.

Returns
