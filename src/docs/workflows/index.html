workflows

run

function

Loads a workflow record by the workflow name in the method or by ID, evaluates its AST actions and output mapping, and writes the evaluated data back to the same invocation envelope. Errors are appended to the envelope's error array. Invocation shape: { method: "workflow.<name>", <name>: [ ...inputs ], organization_id, host } Workflow record shape: { _id, name, enabled, actions }
