uuid

function

Generates an RFC 4122 compliant UUID Version 4 (Universally Unique Identifier). By default, this returns a standard 36-character string. If a custom length less than 36 is provided, it returns a truncated unique identifier (UID).

Parameters

length number
The desired length of the returned identifier (maximum 36).

Returns

string A standard UUIDv4 or a truncated custom-length unique identifier.

Examples

// Returns standard UUIDv4: "f81d4fae-7dec-11d0-a765-00a0c91e6bf6"
uuid(); 
// Returns truncated unique identifier: "f81d4fae"
uuid(8);
